# 🐶 Puppydoku 皇后謎題

網頁版的 Puppydoku 謎題，融合數獨與「八皇后問題」的邏輯。

**線上遊玩：https://jeffcc.github.io/puppydoku/**

也可以直接用瀏覽器開啟 `index.html`，不需安裝任何東西。

訪客統計使用 GoatCounter（只在 GitHub Pages 上啟用），代碼設定在 `index.html` 開頭的 `GOATCOUNTER`。

## 規則

1. 小狗不能相鄰：上下、左右、斜角（周圍 8 格）都不能有其他小狗
2. 每一橫列剛好 1 隻
3. 每一直行剛好 1 隻
4. 每個顏色區域剛好 1 隻

## 功能

- 自動出題：5×5 到 11×11，每題都驗證為唯一解
- 一鍵排除：選取小狗後按 `E`，把同橫列、同直行、周圍 8 格（可選同色區域）標成 ✖；`A` 對全部小狗排除
- 推理提示：顯示下一步的推理過程（藍框為依據、橘框為結論），可一鍵套用
- 衝突與死路提示、復原、計時
- 自動完成：放好倒數第二隻小狗後，若盤面只剩最後一格空格且正是小狗，自動放好並停止計時
- 手機友善：標記模式切換按鈕、防止連點兩下放大畫面

## 操作

| 操作 | 效果 |
|---|---|
| 點一下 | 空白 → ✖ → 🐶 → 空白 |
| 拖曳 | 把經過的空白格標成 ✖ |
| 右鍵 / 長按 | 放置或移除小狗 |
| 手機：棋盤上方 ✕ / 🐶 小圖示 | 決定點一下要放 ✖ 還是 🐶（再點一次取消）；長按放另一種 |
| 方向鍵 / `Space` / `D` / `X` | 移動選取 / 切換 / 小狗 / 叉叉 |
| `E` / `A` | 排除選取小狗周圍 / 全部小狗排除 |
| `Ctrl+Z` | 復原 |
